# 长期能力地图：GSE / CLB 补充草案

## 范围与版本

以 `../long-term-map-2026-10-02/curriculum_map.json` 为基准，保存独立补充版，不改写原报告与原数据。

保留原 140 个节点，为每个节点编写三个原创可观察子目标，共 420 个。三个是本次细化粒度，不是研究证明的最优数量。子目标可以继续拆分，部分是表达、理解或核查动作，不能默认各对应一课。

沿用 CEFR 标签；GSE 帮助寻找更具体的学习目标；CLB 提供成人沟通条件、指标和任务参考。单个标准不能直接决定完整课程顺序。

依用户指示按授权已经通过开展本地工作。这里没有声称已审阅或取得授权文件。

## 数据文件

| 文件 | 内容 |
| --- | --- |
| `curriculum_map.json` | 完整保留的原地图，加子目标、标准候选关系、资源字段、任务蓝图和生成合同 |
| `subtargets.csv` | 420 个原创子目标，便于逐项评审 |
| `gse_objectives.json` | GSE 2022 成人通用、学术、职业目标的原文、分数、技能与 PDF 页码；跨套资料有重复 |
| `gse_grammar.json` | 语法指南的目标、结构、示例、分类与分数；按 PDF 各页表格列位置提取 |
| `official_clb_gse_links.json` | Pearson 2024 三阶段报告发布的 CLB—GSE 条目对应，保留暂定分数标记 |
| `clb_conditions.json` | CLB 2012 听说 12 等级的 48 页原文，包含条件、指标和样例；尚未将所有栏目逐项结构化 |
| `standard_ranges.json` | 出版社 CEFR—GSE 参考区间与 CLB—GSE 对照报告区间 |
| `node_alignment_audit.json` | 每个节点的子目标、候选对应数量及跨原等级提示 |
| `verification.json` | 数据结构、出处和抽取校验结果；不能代替课程专家审核 |

## 对应关系的三种证据

1. **出版社原文与分数**：来自可追溯的目标 PDF。
2. **出版社发布的 CLB—GSE 对应**：来自 2024 年 11 月的 Stage I / II / III 报告；保留条目级出处。
3. **本 App 节点、子目标到标准条目的关系**：本版提供功能检索候选及少量原文功能核对补充。绝大多数仍需逐项语义评审，不能标成专家确认或官方认证。

候选检索采用逐节点英文功能词、CEFR 对应分数区间和少量跨区间参考，优先覆盖不同功能。子目标用具体概念筛选父节点候选，不继承父节点全部条目的“掌握”。这是一套可复现的初步索引方法，检索命中不构成完整语义等价证明。

节点的 `node_gse_score` 保留为空。不把多个候选分数的平均值当作节点等级，更不作为用户的实际 GSE 测评分数。官方 CLB—GSE 链接只在文本与分数均相符时连接。

## 如何驱动 AI

1. 后端选择一个子目标，读取父节点的任务蓝图。
2. 使用已核查的相关标准条目与 CLB 条件；候选未核查时，只按原创目标生成，不能让模型补造条目或分数。
3. 结合用户已知资源，选必要的新词句和支持点。
4. 明确双方角色、信息、隐藏限制和可接受结果，生成学习内容及互动脚本。
5. 分开做提示练习、独立检查、影响任务条件发生变化的迁移检查和隔期检查。
6. 保存每个子目标的音频证据、支持量和判断结果；完成一次教学不直接表示掌握整个父节点。

生成合同的回退模板要求经过审核。本版未为全部目标生成完整审核模板，不能假定回退库已存在。

## 数据与校准缺口

- 所有原节点均完成子目标草案和 CLB 来源定位，但 GSE 直接对应不能覆盖所有支持能力及细分沟通目标；空候选明确保留。
- GSE 词汇领域和原创表达例子已提供，但完整 Toolkit 词义级数据没有导出。本版没有编造任何词义的 GSE 分数。获得官方导出/API 数据后，应补充词义、词性、声音、搭配、等级和来源版本。
- CLB 原文已入库；条件的具体选择、子栏目结构化和本 App 任务参数需专家核对。区间用于定位参考，不是任务成绩自动转换规则。
- 每个子目标都有达成检查、生成合同，每个节点有任务蓝图；完整教学文本、音频、真实角色脚本和评分示例库仍需制作及审核。
- 子目标的去重、边界和前后依赖尚未经过独立课程专家审核；当前语义相关候选需要确认或剔除。
- 真人学习者的起点诊断、生成难度预测、评分一致性、迁移与保持效果尚未验证。不能声称本版已经找到最快路径。

## 复现

在已有源 PDF 的本地目录执行：

```bash
python3 research/long-term-map-gse-clb-2026-10-02/build.py
python3 research/long-term-map-gse-clb-2026-10-02/verify.py
```

新增下载为 GSE 学术、职业 PDF 和 CLB—GSE 官方对照压缩包；原 GSE 通用、语法和 CLB 2012 PDF 已复制到本目录，来源清单、摘要和版本一并保留。
