## 2. 生词本与课程学习、复习

逻辑流：**加入生词本 → 标记待练习 → 课程规划按需选词 → 融入学习或复习任务 → 根据表现更新词汇状态 → 安排后续复习。**

- 收藏时保存词义、来源句和场景，不直接判定为能力缺口。
- 课程规划优先选择与当前沟通目标相关、需要加强或到期复习的生词，纳入 `TeachingAssignment.resource_plan`，用于示范表达或对话任务。
- 用户先尝试：不理解时学习词义和示例；理解但说不出时进行引导练习；能独立使用时安排隔期复习。提示按需提供，实际使用情况需记录。
- 依据有效表现更新 `LearnerProfile.resource_states`；沟通目标是否完成仍按任务要求评价。接受正确改述，不要求用户必须使用指定生词，也不因未使用该词判定能力不足。

生词条目及其与课程、表现证据的关联需补充到数据合同；大量收藏不直接挤占主课程。
