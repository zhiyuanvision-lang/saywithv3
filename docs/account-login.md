# 登录与账号隔离

旧实现通过匿名学习者ID和Bearer令牌隔离数据，没有可找回的身份登录。现在复用旧SayWith账号服务验证手机号验证码、微信授权码和Apple身份令牌；对应的新版学习账号保持稳定，手机号、微信、Apple分别遵循原账号服务的身份关联规则，不按显示姓名自动合并账号。旧版课程和记录不自动迁入新版。

```text
┌─────────────────────────────────┐
│ 品牌图标  背单词练口语          │
│                                 │
│ 登录账号                        │
│ 登录后，接着学、继续练。         │
│ +86  [手机号]                   │
│ [6位验证码]      [获取验证码]   │
│ ○ 同意用户协议和隐私政策        │
│              [登录]             │
│      首次登录将自动创建账号     │
│ （验证码错误时在此显示说明）    │
│          其他方式登录           │
│       [微信]      [Apple]        │
└─────────────────────────────────┘
```

获取验证码与登录按钮不因未勾选协议而禁用，点击后先校验输入；未同意时弹出协议确认，同意后继续原操作，取消不发送短信、不启动第三方授权。微信与Apple采用同一行图标入口，Apple使用系统提供的Apple标识与原生授权流程。验证码可从系统自动填入，倒计时按服务端retry_after计算。微信未安装时隐藏微信入口，仍可选择手机号或Apple；授权取消返回当前页；验证码错误、请求频繁或网络失败显示可重试说明。

登录后进入学习首页，“我的”显示账号名、脱敏手机号和退出登录入口；退出需确认，保留服务器上的学习记录。同设备下次启动读取Keychain：有效访问令牌直接恢复，到期令牌使用刷新令牌换取新凭据；并发请求共享一次刷新，刷新失败时网络错误保留凭据，凭据无效则回到登录页。沿用旧服务默认2小时访问令牌、30天刷新令牌，每次刷新轮换并重新计算有效期；长期未使用、手动退出或服务端撤销后仍需重新登录。

首次身份登录、且该身份尚未有关联的新版账号时，可凭本机旧匿名令牌接管已有学习者记录；接管后旧匿名令牌撤销。该身份已有新版账号时使用已有账号，另一个匿名账号的数据不会自动合并。练习、生成任务和反馈草稿的本地恢复信息按服务地址与用户ID分别存储；切换账号清空内存中的练习、翻译、录音和待发送内容。

后台新增account_identities和account_sessions表，不修改旧服务账号表；学习服务仅存令牌哈希，独立签发访问凭据，刷新和退出使用既有身份服务。个人档案、生成任务、课程、会话、评估、录音、生词本和反馈均按owner限制。课程资源和词典为共享内容，反馈图片沿用供管理员浏览的随机能力链接，不代表所有图片均要求账号登录。

配置：SAYWITH_IDENTITY_API_BASE默认指向旧API的HTTPS根地址；同机生产部署推荐设为旧服务的loopback根地址（不要包含/learning），由受信任Nginx/uvicorn解析客户端地址，再转发给旧服务以保留其登录限流。App复用原Bundle ID、微信AppID、Universal Link与Apple entitlement，微信SDK从旧项目复制到本项目独立维护。

验证范围：身份服务测试使用MockTransport，覆盖三种方式的后端校验、稳定身份、数据隔离、匿名接管、令牌过期、轮换和撤销。真实短信送达、微信App授权回跳、Apple真实账号授权仍需联网真机验收。

2026-10-03交付验证：线上登录接口已发布，审核测试账号的验证码请求、登录、身份验证、刷新和退出通过HTTPS实测（未发送真实短信）；保留上一release可回滚。
